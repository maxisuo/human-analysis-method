# Human Analysis Method Skill

基于微信文章《分析人的训练》三层递进法实现的可交互 Skill。

## 🎯 核心理念

**分析人的本质**：通过"观察→推测→验证"循环，理解人的行为模式，找到兴奋点与脆弱点，最终实现有效干预。

**三层递进**：
1. **第一层：缺点分析** — 训练观察习惯，学会"抓形"
2. **第二层：6+2框架** — 系统化分析（家庭/父母/成长/心理/思维/做事 + 兴奋/脆弱）
3. **第三层：因果链条** — 找矛盾点，分析机制，制定干预策略

## 🎮 使用流程

### Step 1：收集具体事例（至少5个）

**不要空想，只记录事实**：

```
事例1：[行为] 从不主动找我帮忙，但会帮别人
事例2：[背景] 工作三年，认识面广但不张扬
事例3：[外表] 办公桌乱了会受不了，有洁癖
事例4：[背景] 准备金融考试但去年失利
事例5：[言语] 经常说"减肥"，但从未行动
```

### Step 2：选择训练层级

| 层级 | 适合场景 | 训练目标 |
|------|---------|---------|
| **第一层** | 刚入门，观察能力弱 | 学会"抓形"，提炼核心特征 |
| **第二层** | 有一定观察积累 | 系统化分析，找到证据链 |
| **第三层** | 进阶，需干预他人 | 因果机制 + 干预策略 |

### Step 3：查看分析结果

- **弱点分析**：能力/性格/背景三维度缺点
- **6+2框架**：8个维度的详细分析
- **矛盾点**：表面矛盾与深层原因
- **兴奋/脆弱点**：可操作的人际影响点
- **干预策略**：正向（建立关系）/负向（竞争时用）

### Step 4：验证与修正

- 在现实中观察验证推测
- 记录哪些猜对了，哪些错了
- 修正分析，丰富样本库

## 🔍 6+2 框架详解

### 6个基本点

| 维度 | 分析内容 | 证据来源 |
|------|----------|----------|
| **家庭条件** | 经济状况、消费能力 | 用车、旅游、用品品牌 |
| **父母关系** | 亲密程度 | 是否提父母、亲密关系模式 |
| **成长经历** | 阻力大小、教育方式 | 是否中规中矩、冲劲 |
| **心理状态** | 内向/外向、情绪模式 | 社交表现、发脾气频率 |
| **思维方式** | 感性/理性、严谨度 | 说话逻辑、做事细致 |
| **做事方式** | 时间观、自我要求 | 守时/拖延、对人vs对己 |

### +2 关键点

**兴奋点**（让他愿意配合你）：
- 触发场景：聊什么话题他眼睛发亮？
- 行为表现：兴奋时的具体表现
- 利用建议：如何创造让他兴奋的环境

**脆弱点**（让他消沉）：
- 触发场景：什么话题他回避？
- 行为表现：低落时的表现
- 干预方法：竞争时如何用（⚠️慎用）

## 💡 核心方法

### 1. 从矛盾点切入

**例子**：
- 家庭条件好 → 为什么内向沉闷？（正常应该更自信）
- 严谨中有冒失 → 为什么？（"严谨"是压制的样子）

**方法**：用社会普遍的"正常"去分析具体人的"不正常"。

### 2. "猜"是必要的训练

- 线索少时，猜**10种可能**，不是猜1种
- 多猜 → 多备选 → 后续观察中筛选 → 找到最贴切的
- 样本库越大，猜得越准

### 3. 区分"描述"和"分析"

- **描述**："他工作三年了"
- **分析**："工作三年仍被动 → 说明成长阻力小，缺乏竞争意识"（发现"看不到"的东西）

### 4. 用具体事例支撑

每个结论至少2个事例支撑，否则只是臆测。

## 🌐 应用场景

### 场景1：同事不配合

**问题**：同事总是不主动配合我的工作。

**使用 Skill**：
1. 收集同事的具体事例（他对别人怎么做的？什么时候配合？）
2. 分析他的兴奋点（什么让他愿意帮你）
3. 切入点：发现他喜欢被认可专业能力 → 先请教他问题，再提协作

### 场景2：下属拖拉

**问题**：下属工作拖拉，但对别人要求很高。

**分析**：
- 做事方式矛盾：对己宽对人严
- 原因：成长环境让他认为"规则应该遵守，但自己可以例外"
- 干预：让他参与制定规则（自己定的就会遵守）

### 场景3：拉近人际关系

**问题**：新朋友不知道如何拉近距离。

**分析**：
- 观察兴奋点（聊什么他眼睛发亮）
- 创造场景（约他打牌/聊书）
- 避免脆弱点（不问他考试失利）

### 场景4：自我认知

**⚠️ 文章明确说：别分析自己**

**原因**：
1. 分析别人是**向外看**，激发本能，改善心理
2. 分析自己是**向内看**，容易自我攻击
3. 适度复盘行为影响可以，但不要分析"我是怎样的人"

## ⚠️ 伦理警告

### ✅ 允许
- 分析是为了更好协作
- 发现兴奋点用于建立良好关系
- 了解脆弱点用于避免踩雷

### ❌ 禁止
- 负向干预用于恶意操控
- 将分析结果公开传播
- 用于歧视或排斥他人

### ⚠️ 慎用
- 负向干预仅限正当竞争
- 兴奋点利用要真诚，不要变成套路

## 📊 训练计划

### 第1-2周：第一层训练

**每日**：
1. 选1个身边的人
2. 记录10个具体事例
3. 总结3-5个核心特征
4. 自问：一说这特征，别人能认出他吗？

### 第3-4周：第二层训练

**每周**：
1. 用6+2框架分析同一个人
2. 每一点至少2个事例支撑
3. 找出1-2个矛盾点
4. 推测兴奋点/脆弱点（标记"待验证"）

### 第5周+：第三层训练

1. 选重要人物（老板/关键客户/伴侣）
2. 完成因果链条分析
3. 制定干预策略
4. 在实践中验证、修正

## 🆚 与能力评估的区别

| | 能力评估（雷达图） | 本文"分析人" |
|---|-------------------|-------------|
| **目的** | 衡量能力水平 | 理解行为模式，实现干预 |
| **方法** | 打分、量化 | 观察事例、推测因果 |
| **输出** | 雷达图、评分 | 核心特征、兴奋/脆弱点 |
| **时间** | 一次性 | 长期观察 |
| **焦点** | **能力**（能做什么） | **动机**（为什么做） |

## 🎯 常见误区

| 误区 | 纠正 |
|------|------|
| "分析别人不礼貌" | 分析是内心活动，不说出来。为了更好应对。 |
| "线索少就猜会先入为主" | 多猜（10种可能），后续验证筛选，不是只猜一种。 |
| "分析自己才能进步" | 文章明确说"别分析自己"，容易自我攻击。 |
| "要永远准确" | 一开始不是为了准确，是培养习惯。准确度在实践中提高。 |
